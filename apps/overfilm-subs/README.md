# OverFilm 자막 추출 (overfilm-subs)

OverFilm에서 자막 추출만 떼어 낸 독립 프로그램입니다. 영상이나 오디오 파일을 넣으면 한국어 자막(SRT)을
만듭니다. 인터넷은 처음 모델을 받을 때만 쓰고, 소리는 이 컴퓨터 밖으로 나가지 않습니다.

- 음성 인식: Qwen3-ASR-1.7B (오버워치 영웅·용어 목록을 문맥으로 넣음), 단어 시간: Qwen3-ForcedAligner-0.6B.
  둘 다 Rust(candle)로 옮긴 것이라 Python이나 다른 프로그램이 필요 없습니다.
- 인식 뒤 단어집 교정(`packs/overwatch/ko/glossary`, 프로그램 안에 들어 있음): 자주 틀리는 표기, 이름 근접 오타,
  욕설 초성(씨발 → ㅅㅂ, 끌 수 있음).
- 맞춤법·띄어쓰기: 떨어진 조사 붙이기(이거 는 → 이거는), 의존 명사 띄우기(할수있다 → 할 수 있다, 하는거 → 하는 거),
  자주 틀리는 표기(할께요 → 할게요, 됬다 → 됐다, 그럴려면 → 그러려면, 벤 → 밴).
- 숫자: 말로 한 숫자를 자막식 숫자로(오 시즌 → 5시즌, 일 위 → 1위, 사십칠 퍼센트 → 47%, 여섯 개 → 6개). 뒤에
  단위가 올 때만 바꾸므로 '이 영웅', '이번 시즌'은 그대로입니다. 끌 수 있음(`--no-digits`).
- 자막: 최대 두 줄, 한 줄 16자. 글자 수가 아니라 말의 마디에서 끊습니다: 문장 끝·쉼표·연결 어미(…는데, …지만,
  …해서, …고) 뒤가 가장 자연스럽고, 조사 뒤도 괜찮고, 숨 쉬는 틈이 있으면 그쪽으로 끊습니다. '할 수 있다',
  '하고 있다', '하는 거 같다', '너무 강한', '완전히 바뀌었다'처럼 붙어 다니는 말은 가르지 않습니다.
- 표시 시간: 목소리보다 0.12초 먼저 뜨고, 말이 끝난 뒤 0.4초 남습니다. 말이 빨라 읽기 어려우면 다음 자막이
  올 때까지 초당 12자로 읽을 만큼 더 남기고(말 끝에서 최대 1.5초), 최소 1초는 보입니다. 다음 자막과 0.5초보다
  짧은 틈은 메워 화면이 깜빡이지 않고, 자막끼리 겹치지 않습니다. 설정의 '자막 모양'이나 `--lead 120 --hold 400
  --cps 12`로 바꿀 수 있습니다.
- 목소리 구별: 말하는 사람이 몇 명인지 세고, 사람이 둘 이상이면 자막마다 `(화자1)`, `(화자2)`처럼 누가 말했는지
  붙입니다. 자막 하나에 두 사람 말이 섞이지 않습니다. 사람 수를 알면 정해 줄 수 있고(`--speakers 3`), 이름은 나중에
  바꿀 수 있습니다(`relayout … --rename 화자1=아이치`, MCP `rename_speaker`). 사람마다 SRT를 따로 저장할 수도 있습니다
  (`--per-speaker`, Premiere에서 해설자마다 자막 트랙을 따로 둘 때).
- 목소리 등록: 스트리머·해설자처럼 자주 나오는 사람의 목소리를 한 번 등록해 두면(그 사람만 말하는 10~30초), 다음
  영상부터 `화자1` 대신 그 이름이 붙고, **등록한 목소리만 자막**을 켜면 그 사람 말만 자막으로 만듭니다(게임 음성·다른
  사람 제외). `overfilm-subs voice add 이름 영상.mp4 --from 1:23 --to 1:45`, 창의 **목소리** 화면(검토 화면에서 화자를 오른쪽 클릭 › 이 목소리 등록…), MCP `add_voice`.
- 게임 음성: 영웅 궁극기 대사·아나운서 같은 게임 소리를 찾아 자막에서 뺍니다(기본). `(게임)`으로 표시하거나 그대로 둘 수도
  있습니다(`--game-voice label|keep`). 자세한 방식과 한계는 아래 "목소리 구별과 게임 음성".
- 추임새 빼기(끌 수 있음, 기본 꺼짐): "어, 음, 으음" 같은 군말과 "그 그 그게", "아니 아니 아니" 같은 말 더듬기를 자막에서 뺍니다.
  단어 시간 파일에는 남아 있어서 끄면 다시 나옵니다(`--clean`, 검토 화면의 **추임새 빼기**).
- 자신 없는 단어: 인식기가 확신하지 못한 단어(확률 70% 미만. 아이치 영상에서 표시된 단어의 절반쯤이 실제로 틀린 단어였음)를 검토 화면의 **검토할 곳 › 자신 없는 단어**에 모읍니다.
  단어집에 없는 오인식도 여기서 찾을 수 있습니다.
- 결과: 입력 파일 옆에 `이름.srt`(UTF-8 BOM, Premiere에서 바로 가져오기)와 `이름.overfilm.json`(단어별 시간, 화자, 인식 확신도).
  **내보내기**로 WebVTT(유튜브), ASS(화자마다 색), 대본 TXT, 프레임에 맞춘 SRT도 만듭니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `OverFilmSubs.exe` | 창 프로그램. 더블클릭해서 엽니다. |
| `overfilm-subs.exe` | 명령줄과 MCP 서버. |

## 쓰는 법 (창)

창은 Windows 11 기본 앱처럼 왼쪽에 **새 자막 · 최근 · 목소리**, 맨 아래에 **설정**이 있습니다.

1. `OverFilmSubs.exe`를 엽니다. 처음이면 위쪽 알림의 **지금 받기**로 음성 인식 모델(약 6.5GB)을 미리 받아 둘 수 있습니다.
2. 파일을 창에 끌어다 놓거나 **파일 선택**을 누릅니다 (mp4, mov, mkv, webm, avi, mxf, ts, mp3, m4a, aac, wav, flac,
   ogg, opus). exe 아이콘에 파일을 끌어 놓거나 "연결 프로그램"으로 열어도 됩니다(.srt를 주면 바로 검토 화면).
3. **영상 종류**를 고릅니다. 고르면 아래 세부 설정이 맞춰집니다.
   - 일반 게임 영상: 말하는 사람을 자동으로 셉니다.
   - 스트리머 방송: 등록한 목소리의 말만 자막으로 만듭니다(게임 소리·다른 사람 제외).
   - 대회 해설: 팀·선수 이름을 문맥에 넣고, 해설자마다 SRT를 따로 저장합니다.
   단어집에 없는 이름은 **추가 이름·용어**에, 사람 수를 알면 **목소리 구별 › 사람 수**에 적습니다. **자막 모양**을 펼쳐
   줄 길이를 바꾸면 오른쪽 미리보기가 그 설정으로 끊어 보여 줍니다.
4. **자막 만들기**. 진행 화면에 단계(모델 준비, 소리 읽기, 음성 인식, 목소리 구별, 교정·저장)와 남은 시간이 나옵니다.
5. 검토 화면: 가운데 표(번호·시작·끝·길이·화자·자막), 오른쪽 **검토할 곳**(종류별 개수, 누르면 그것만 보임),
   왼쪽 **화자**. 줄을 누르면 아래 칸에서 글자를 고치거나 단어집 제안대로 **고치기**, **무시**할 수 있습니다(F8: 다음 곳,
   Ctrl+Enter: 저장). 화자를 오른쪽 클릭하면 이름 바꾸기, 다른 화자와 합치기(같은 이름을 주어도 합쳐짐), 게임 음성으로
   돌리기, **이 목소리 등록…**(그 사람이 혼자 말한 구간을 골라 둠)을 할 수 있습니다. 고치면 바로 저장되고 처음 고칠 때
   `.srt.bak`을 남깁니다. **실행 취소**로 되돌립니다.
6. 검토 화면에서 더 할 수 있는 것:
   - **찾아 바꾸기**(Ctrl+H): 전체에서 바꾸고, **단어집에도 넣기**를 켜면 다음 자막부터 자동으로 고칩니다.
   - **이 부분 다시 인식**: 줄을 고르고(Shift+클릭으로 여러 줄) 그 구간의 소리만 다시 인식합니다. 그 구간에 나오는 이름을
     적어 주면 더 정확합니다. 다른 곳에서 손으로 고친 글자는 그대로 둡니다.
   - **기록**: 저장할 때마다 남긴 상태(최근 100개)를 시간·고친 내용과 함께 보여 주고, 어느 시점으로든 되돌립니다. 기록은
     자막 폴더가 아니라 `%LOCALAPPDATA%\OverFilm\history`에 있습니다.
   - **내보내기**: SRT, WebVTT, ASS, 대본 TXT. 영상의 프레임 수(23.976~60)를 고르면 자막이 프레임 경계에서 바뀌고, 자막
     사이에 빈 프레임을 둘 수 있습니다.
   - 같은 고침을 세 번 하면(예: 전국퀸 → 정커퀸) 위쪽에 "단어집에 넣을까요?"가 뜹니다.
7. 왼쪽 **단어집**: 내가 더한 표기(맞는 표기, 틀린 표기, 메모)를 더하고 고치고 지웁니다. 찾기는 내장 단어집(영웅·선수·팀·용어)도
   함께 찾아서 이미 있는지 알려 줍니다. 직접 고친 내용에서 찾은 후보도 여기서 넣거나 무시합니다.
8. 준비 화면의 **끝나면**: 다 만들면 알림을 띄우고(작업 표시줄도 깜빡임), **절전 모드로**를 고르면 1분 동안 취소할 수 있게
   기다린 뒤 컴퓨터를 재웁니다. 긴 방송을 밤에 걸어 둘 때 씁니다.

GPU 사용 여부, 모델 폴더, Claude Desktop 연결 설정은 **설정**에 있습니다. 창은 최근 목록과 설정을 모델 폴더 옆
(`%LOCALAPPDATA%\OverFilm\recent.json`, `gui.json`)에 저장합니다.

모델 위치: `%LOCALAPPDATA%\OverFilm\models`. 프로그램 옆에 `models` 폴더가 있으면 그것을 씁니다
(USB에 통째로 들고 다닐 때). 다른 곳을 쓰려면 환경 변수 `OVERFILM_MODELS`.

## 명령줄

```bat
overfilm-subs models
overfilm-subs extract "경기.mp4" --mode commentary --terms "새 선수, 새 팀"
overfilm-subs extract "방송.m4a" -o 자막.srt --no-mask --line-chars 18
overfilm-subs review 자막.srt          검토할 곳 목록
overfilm-subs fix 자막.srt             단어집 교정 적용 (원본은 자막.srt.bak)
overfilm-subs relayout 경기.overfilm.json --line-chars 18   인식을 다시 하지 않고 자막만 다시 나누기
overfilm-subs relayout 경기.overfilm.json --lead 200 --hold 600 --cps 10   자막을 더 일찍 띄우고 더 오래 남기기
overfilm-subs extract "합방.mp4" --speakers 3 --per-speaker     사람 3명, 사람마다 SRT도 저장
overfilm-subs extract "방송.mp4" --game-voice label             게임 음성을 빼지 않고 (게임)으로 표시
overfilm-subs extract "녹화.mkv" --audio-track 2 --speakers 1    오디오 트랙 2(따로 녹음한 마이크)만, 혼자 말함
overfilm-subs relayout 합방.overfilm.json --rename 화자1=아이치 --rename 화자2=게스트   화자 이름 바꾸기
overfilm-subs voice add 아이치 "방송.mp4" --from 1:23 --to 1:45   목소리 등록 (그 사람만 말하는 구간)
overfilm-subs extract "방송.mp4" --only-voices                    등록한 목소리(스트리머)의 말만 자막
overfilm-subs voice list
overfilm-subs extract "방송.mp4" --clean                          추임새·말 더듬기 빼기
overfilm-subs extract "방송.mp4" --from 1:00:00 --to 1:20:00      이 구간만 (자막 시간은 원본 기준)
overfilm-subs redo 방송.srt --from 00:12:03,000 --to 00:12:20,000 --terms "새 선수"   이 부분만 다시 인식
overfilm-subs export 방송.srt --format vtt                        유튜브용 WebVTT
overfilm-subs export 방송.srt --format ass                        화자마다 색이 다른 ASS
overfilm-subs export 방송.srt --format srt --fps 29.97 --gap 2 -o 방송.2997.srt   프레임에 맞추고 자막 사이 2프레임
overfilm-subs export 방송.srt --format txt                        대본 ([00:01:02] 화자1: 말)
```

## MCP로 검토하기 (Claude Desktop)

창의 **설정 › Claude**가 아래 설정을 경로까지 채워서 보여 주고 복사해 줍니다. Claude Desktop → 설정 → 개발자 →
설정 편집(`claude_desktop_config.json`)에 넣고 Claude Desktop을 다시 시작합니다.

```json
{
  "mcpServers": {
    "overfilm-subs": { "command": "C:\\OverFilm\\overfilm-subs.exe", "args": ["mcp"] }
  }
}
```

대화에서 할 수 있는 일:

| 도구 | 하는 일 |
|---|---|
| `extract_subtitles`, `job_status`, `cancel_job` | 자막 추출 (백그라운드, 진행률 확인) |
| `read_subtitles` | 자막 읽기 |
| `review_subtitles` | 검토: 단어집·맞춤법과 다른 표기(고칠 글자 제안), 인식이 자신 없던 단어(`unsure`), 읽기 속도, 줄 길이·줄 수, 너무 짧음, 겹침, 반복, 빈 자막 |
| `find_silences` | 말 없는 구간 표시 (지우지 않음) |
| `edit_subtitle`, `split_subtitle`, `merge_subtitles`, `delete_subtitle` | 고치기 (처음 고칠 때 `.srt.bak` 백업) |
| `apply_glossary` | 단어집·맞춤법·숫자 교정 적용 |
| `relayout_subtitles` | 줄바꿈 다시 하기 |
| `add_voice`, `list_voices`, `remove_voice` | 목소리 등록·목록·삭제 (`extract_subtitles`의 `only_voices`로 그 사람 말만 자막) |
| `list_speakers`, `rename_speaker` | 구별된 화자 목록(말한 시간, 게임 음성 여부), 이름 바꾸기·게임 음성으로 돌리기 (자막 다시 만듦) |
| `add_glossary_term`, `list_glossary_terms`, `remove_glossary_term` | 사용자 단어집(`%LOCALAPPDATA%\OverFilm\glossary\user.tsv`) 더하기·목록·지우기. `edit_subtitle`은 같은 고침이 세 번째면 `glossary_suggestion`으로 알려 줌 |
| `rerecognize_range` | 한 구간만 다시 인식 (백그라운드, `job_status`). `extract_subtitles`도 `from`/`to`로 구간만 |
| `export_subtitles` | SRT·VTT·ASS·TXT로 내보내기, 프레임 맞춤(`fps`)과 자막 사이 빈 프레임(`gap_frames`) |
| `list_history`, `restore_version` | 저장할 때마다 남긴 기록 보기, 한 시점으로 되돌리기 |

예: "경기.mp4 자막 뽑고, 끝나면 검토해서 선수 이름 틀린 것 고쳐 줘."

## 목소리 구별과 게임 음성

- **어떻게**: 인식된 단어가 있는 곳을 1.5초 창으로 0.5초마다 훑으며 목소리 특징(256개 숫자)을 뽑고, 비슷한 것끼리
  묶어(평균 연결 군집, 코사인 거리 0.7에서 멈춤) 사람 수를 정합니다. 말이 10초(짧은 영상은 전체의 8%)가 안 되는
  목소리는 가장 비슷한 사람에게 합칩니다. 단어마다 각 사람과 얼마나 비슷한지 점수를 매기고, 사람이 바뀌는
  곳은 쉼(0.4초 이상)이나 문장 끝에서만 쉽게 바뀌도록 정합니다. 그래서 한 문장이 중간에 다른 사람으로 쪼개지지 않습니다.
- **모델**: WeSpeaker ResNet34 (VoxCeleb으로 학습, pyannote 배포본, CC-BY-4.0, 27MB)와 겹친 말용 pyannote segmentation 3.0
  (MIT, 6MB). 처음 한 번 받습니다.
  Rust(candle)로 옮겼고 원본(ONNX)과 결과가 같습니다(코사인 1.0000).
- **정확도**: 한국어 낭독 음성(Zeroth, 10명)으로 만든 2~5명 대화 24개(각 2분 30초, 짧은 맞장구 포함)에서 사람 수
  24/24 정답, 단어의 화자 오류 1.9%. 실제 방송은 말이 겹치고 게임 소리가 섞여 이보다 어렵습니다.
- **게임 음성**: `packs/overwatch/ko/voicelines.tsv`(약 2만 줄: 대부분 영웅의 궁극기 대사·아나운서, 그리고 영웅 40명의
  한국어 대사. 안란·디몬·도미나·시온·시에라는 아직 없음)와 글자로 맞춰 봅니다. "방어구가 필요해" 같은 소통 대사나 "아니거든요"
  같은 짧은 일상 대사는 사람도 하는 말이라 그것만으로는 빼지 않습니다. 궁극기
  대사는 다섯 글자 이상, 다른 대사는 여덟 글자 이상이 같으면(여덟 글자 이상은 한두 글자 달라도) 게임 음성으로 보고, 한 목소리의 말이 대부분 대사이면 그 목소리 전체를 '게임 음성'으로
  봅니다. 목록에 없는 대사는 못 찾고, 스트리머가 대사를
  따라 하면 같이 빠질 수 있습니다. 잘못 빠졌으면 `--game-voice label`로 다시 만들어 확인하세요.
- **목소리 등록**: 샘플의 목소리 특징 평균을 `%LOCALAPPDATA%\OverFilm\voices\이름.json`에 저장합니다(소리는
  저장하지 않음). 영상에서 구별된 사람 중 등록한 목소리와 충분히 가까운(코사인 거리 0.55 이하) 사람에게 그 이름을
  붙이고, 가장 가까운 짝부터 하나씩만 붙입니다. 등록한 사람은 말이 적어도 따로 남깁니다.
  합성 대화 24개로 시험하면 단어의 97.9%에 맞는 이름이 붙고, 틀린 이름은 2.1%입니다.
- **겹친 말**: 두 사람이 동시에 말하는 곳을 pyannote segmentation 3.0(MIT, 6MB, 로그인 없이 받는 공개 사본)으로 찾아
  단어마다 '같이 말한 사람'을 붙입니다. 두 단어 이상, 1초 이상 이어지면 자막에 `(화자1·화자2)`로 표시하고, 사람별
  자막(`--per-speaker`)과 등록한 목소리만 자막(`--only-voices`)에는 다른 사람 말 위에 겹쳐 한 말도 넣습니다. 게임 음성
  위에 사람이 말한 단어(대사가 아닌 것)는 사람 말로 돌립니다. 합성 대화(실제로 두 목소리가 들리는 단어 301개)에서 겹친 단어의 79%를 찾고
  68%는 두 사람 모두 맞혔으며, 겹치지 않은 단어를 겹쳤다고 한 경우는 2.8%입니다. 사람 말 위에 영웅 대사가 겹치는 합성 대화에서는
  79%를 찾고 63%는 두 쪽 모두 맞혔습니다(오탐 4.9%). 사람마다 목소리 특징을 뽑을 때 겹친 구간은 빼서, 혼자 말한 단어의 화자 오류도 5.2→4.8%(영웅 섞인 시험은 5.7→4.8%)로 줄었습니다. 인식기는 한 줄로만 받아 적으므로
  겹친 구간의 어느 단어를 누가 했는지까지는 나누지 못합니다. 4코어 CPU에서 소리 10분에 약 1분 더 걸립니다.
- **한계**: 겹친 말의 4분의 1 정도는 아직 놓칩니다(주로 한쪽 목소리가 작을 때). 목소리가 아주 비슷하거나 한 사람이 목소리를 크게 바꾸면
  틀릴 수 있습니다. 틀린 이름은 `rename_speaker`로 고치고, 사람 수를 알면 정해 주는 것이 가장 확실합니다.

## 속도와 사양

- 그래픽카드(GPU)가 있으면 씁니다: AMD 라데온, NVIDIA, 인텔 모두 Windows의 Vulkan이나 DX12로 돌아가고 따로 설치할 것은 없습니다. 그래픽 메모리는 약 4GB를 씁니다. 화면의 '그래픽카드(GPU) 사용'을 끄거나 `--cpu`를 주면 CPU만 씁니다.
- GPU가 없거나 GPU에서 오류가 나면 자동으로 CPU로 이어서 처리합니다. 완료 메시지에 어느 쪽에서 돌았는지 나옵니다.
- CPU만 쓸 때는 AVX2가 있는 x86-64 CPU(2013년 이후 인텔·AMD)가 필요하고 메모리는 약 4GB를 씁니다. 4코어 기준 소리 1분에 약 2분 40초 걸립니다 (모델 불러오기 포함, 2분짜리 영상 실측 5분 15초).

- 목소리 구별도 그래픽카드에서 돕니다(시작할 때 CPU와 결과를 비교해 다르면 CPU로). CPU만 쓰면 소리 10분에 1~2분 더
  걸립니다(4코어 실측: 20초에 2.3초). 끄거나(`--speakers off`) 사람 수를 1명으로 정하면(`--speakers 1`) 이 시간이 빠집니다.
  10분짜리 해설 영상 전체(인식 + 목소리 구별)를 4코어 CPU만으로 처리하는 데 32분 걸렸습니다.

## 빌드

```sh
# Windows에서
cargo build --release -p overfilm-subs
# 리눅스에서 Windows용 (mingw-w64 필요)
CARGO_TARGET_X86_64_PC_WINDOWS_GNU_LINKER=x86_64-w64-mingw32-gcc \
CARGO_TARGET_X86_64_PC_WINDOWS_GNU_RUSTFLAGS="-C target-cpu=x86-64-v3" \
cargo build --release --target x86_64-pc-windows-gnu -p overfilm-subs
```

`target-cpu=x86-64-v3`(AVX2)가 없으면 8비트 계산이 SIMD를 못 써서 몇 배 느려집니다.
